    High-Efficiency Gas Water Heater Installation in Wentzville, MO

    High-efficiency gas heaters use condensing technology to pull extra heat out of the exhaust. Condensing units vent through PVC and need a condensate line, so placement and install work differ from a standard tank. Energy Star models qualify for some rebates.     Traditional Tank Gas Water Heater Installation in Wentzville

    Tank gas heaters are still the workhorse in most garages and utility rooms, usually 40 or 50 gallons. Each install gets a new gas connector and drip leg, a vent connector pitched upward and a relief line piped where code allows. We strap it if code calls for it. Your household sets the size.

    Propane Water Heater Installation in Wentzville

    Propane homes need heaters set up for propane, not natural gas. Propane runs at a different pressure and needs a smaller burner orifice, so we install propane-specific models or convert units with the manufacturer kit where the manual allows it. We work with your supplier. We test all fittings.
